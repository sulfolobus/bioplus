## 参考命令（手动执行）

### 方案 A：切换为 SSH Remote（推荐）

1. 在 GitHub 账号中添加本机 SSH 公钥（若尚未添加）。
2. 切换 remote：

```bash
git remote -v
git remote set-url origin git@github.com:sulfolobus/bioplus.git
git push origin main
```

### 方案 B：使用 Token（HTTPS）

1. 在 GitHub 创建 Personal Access Token（classic 或 fine-grained 均可，至少需要仓库写权限）。
2. 推送时使用 Token 作为密码（或配置 credential helper）：

```bash
git push origin main
```

> 注：GitHub 已不再支持使用账户密码进行 HTTPS 推送。
