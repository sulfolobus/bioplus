## 💡 购书建议

1. **按需购买**：先明确自己的学习目标，再选择对应阶段的书籍
2. **经典优先**：经典教材经得起时间考验，基础阶段选择经典教材最稳妥
3. **配合使用**：一本主教材 + 一本辅导书 + 一本习题集 = 最佳学习组合
4. **电子版 vs 纸质版**：教材和参考书建议买纸质版方便做笔记，科普读物可以选择电子版
5. **二手书**：大学教材价格较高，可以考虑二手书或图书馆借阅
