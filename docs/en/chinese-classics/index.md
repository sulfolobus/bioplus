# Chinese Classics

This section is a long-term study column for major Chinese classics. Each daily issue advances exactly one natural unit in sequence (no skipping, no repetition) and is published to both the website and a WeChat-ready manuscript.

## How it works

- Main column: `classics-study`
- Persistent progress file: repository root `classics_study_progress.yml`
- Rhythm: one issue per day (default run time 05:00)
